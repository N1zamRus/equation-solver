SPECIAL VALUES BEHAVIOR TABLE
WITHOUT SIGNED ZERO
==============================

FORMAT
------

Каждый раздел устроен так:

Тип данных
    Сложение с ним
    Вычитание с ним
    Умножение с ним
    Деление с ним
    Сравнения с ним
    Унарные операции

Здесь рассматривается вариант WITHOUT SIGNED ZERO:
    +0 и -0 не различаются
    -0 нормализуется в 0
    ноль не хранит знак


ОБОЗНАЧЕНИЯ
-----------

nan       = Not a Number
+inf      = положительная бесконечность
-inf      = отрицательная бесконечность

positive  = конечное число > 0
negative  = конечное число < 0
0         = обычный ноль без знака

finite    = positive | negative | 0
x         = любое значение: nan | +inf | -inf | positive | negative | 0

============================================================
MIN / MAX
============================================================

Политика для твоего BigFloat:
если хотя бы один аргумент nan, возвращаем nan.


min/max с NaN
-------------

min(nan, nan)        -> nan
max(nan, nan)        -> nan

min(nan, +inf)       -> nan
max(nan, +inf)       -> nan

min(+inf, nan)       -> nan
max(+inf, nan)       -> nan

min(nan, -inf)       -> nan
max(nan, -inf)       -> nan

min(-inf, nan)       -> nan
max(-inf, nan)       -> nan

min(nan, positive)   -> nan
max(nan, positive)   -> nan

min(positive, nan)   -> nan
max(positive, nan)   -> nan

min(nan, negative)   -> nan
max(nan, negative)   -> nan

min(negative, nan)   -> nan
max(negative, nan)   -> nan

min(nan, 0)          -> nan
max(nan, 0)          -> nan

min(0, nan)          -> nan
max(0, nan)          -> nan


min/max без NaN
---------------

min(+inf, +inf)      -> +inf
max(+inf, +inf)      -> +inf

min(-inf, -inf)      -> -inf
max(-inf, -inf)      -> -inf

min(+inf, -inf)      -> -inf
max(+inf, -inf)      -> +inf

min(-inf, +inf)      -> -inf

min(+inf, finite)    -> finite
max(+inf, finite)    -> +inf

min(finite, +inf)    -> finite
max(finite, +inf)    -> +inf

min(-inf, finite)    -> -inf
max(-inf, finite)    -> finite

min(finite, -inf)    -> -inf
max(finite, -inf)    -> finite

min(0, positive)     -> 0
max(0, positive)     -> positive

min(positive, 0)     -> 0
max(positive, 0)     -> positive

min(0, negative)     -> negative
max(0, negative)     -> 0

min(negative, 0)     -> negative
max(negative, 0)     -> 0

min(positive, negative) -> negative
