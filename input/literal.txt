SPECIAL VALUES TABLE WITHOUT SIGNED ZERO
========================================

Обозначения:
------------
finite      = любое конечное число
nonzero     = любое конечное число, кроме 0
positive    = конечное число > 0
negative    = конечное число < 0
0           = обычный ноль, без знака
+inf        = положительная бесконечность
-inf        = отрицательная бесконечность
nan         = Not a Number
x           = любое значение
sign(a,b)   = знак по обычным правилам:
              + * + = +
              + * - = -
              - * + = -
              - * - = -

13. Общий порядок значений
--------------------------

Если не учитывать nan:

-inf < negative finite < 0 < positive finite < +inf

nan не находится ни меньше, ни больше, ни равен чему-либо.

То есть:

nan == anything                   false
nan != anything                   true
nan < anything                    false
nan > anything                    false

16. Короткие правила реализации
-------------------------------

1. Если хотя бы один операнд nan:
   результат почти всегда nan.

2. Если операция даёт неопределённость:
   результат nan.

3. Если бесконечности одного направления складываются:
   +inf + +inf -> +inf
   -inf + -inf -> -inf

4. Если бесконечности противоположных направлений складываются:
   +inf + -inf -> nan
   -inf + +inf -> nan

5. Если конечное nonzero делится на 0:
   positive / 0 -> +inf
   negative / 0 -> -inf

6. Если 0 делится на 0:
   0 / 0 -> nan

7. Если finite делится на infinity:
   finite / +inf -> 0
   finite / -inf -> 0

8. Если infinity умножается на 0:
   infinity * 0 -> nan

9. Если infinity делится на finite nonzero:
   знак результата определяется знаком infinity и знаком finite.

10. Если infinity делится на infinity:
    результат nan.

11. Ноль всегда хранится как обычный 0:
    -0 не существует.
